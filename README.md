## 🧬 About

I work between biology and engineering — the part where a question about a genome
turns into code, a model, and eventually a result somebody else can reproduce.

```python
class ComputationalBiologist:
    """Someone who reads both FASTQ and stack traces."""

    domains = ["genomics", "single-cell", "transcriptomics"]
    methods = ["deep learning", "statistical inference", "sequence analysis"]
    daily   = ["python", "pytorch", "bash", "slurm"]

    def philosophy(self) -> str:
        return "A result you cannot rerun is an anecdote, not a finding."
```

- 🔬 **Research interests** — single-cell and spatial transcriptomics, variant
  interpretation, and representation learning on biological sequence.
- ⚙️ **Engineering interests** — making scientific code behave like production
  software: typed, tested, containerised, and runnable by someone who is not me.
- 🧪 **Currently curious about** — how far foundation models can be pushed on
  genomic data before biology stops being merely a token stream.
- 🌱 **Currently learning** — Kubernetes, and more Rust than is strictly necessary.

## 🧫 How I like to work

Pinned environments and container digests instead of a lab notebook entry that says
"ran it on the cluster". Every derived file should trace back to an accession and a
command line. If a collaborator cannot rerun the analysis from the README, the README
is not finished yet. And when a new method shows up: new method, old method, same
held-out data, then we talk.
